# 自前ハーネスをプラグイン化して導入を統合する

## やりたいこと

本ハーネス所有のスキル・テンプレート・接続情報を配布可能なプラグインにし、必要なら一つのコマンドから自前プラグインと上流公式インストーラーを順に扱えるようにする。

## 背景・現状

これは現時点では着手しない将来タスクである。ローカル・リポジトリ単位のスキル開発を越えて再利用物を配る場合はプラグインが適するが、先に包装すると実際の共通境界が分からない。

## 着手条件

- 導入済みリポジトリが3件以上ある。
- 手作業の反復、導入ミス、更新負担のいずれかが台帳で実測されている。
- T-0009までの更新・巻戻し・撤去が成功している。
- T-0011で配布方式と保守責任を比較し、プラグイン化または一括導入の採用が承認されている。
- 利用者がプラグイン化の範囲を承認している。

## 進め方

着手条件を満たした時点で詳細化する。一括導入は自前部分の導入、上流公式インストーラーの呼出、重複・プロファイル・ライセンス・検証の確認に限定し、上流スキル本体を自前パッケージへ同梱しない。

## 決定と根拠

- 複数リポジトリへ再利用スキルを配る場合はプラグインを優先する。→ SPEC §9.3
- 上流の配布経路と更新責任は統合しない。→ SPEC §9.1
- トリガー前は明示手順とGitコミットで運用する。→ SPEC §11
- 2026-09-07のT-0011検討で、利用者はプラグイン化を別タスクで扱う意向を示した。本タスクをその実装先とし、文書の入口整備はT-0014へ分ける。配布の追加便益と必要時保守の判断はT-0011を参照する。→ T-0010
