# プロジェクト設定

初回導入時に既存文書・設定・コマンドを調べて未設定欄を埋める。既存設定があれば本雛形で上書きせず、役割の不足だけを補う。

## 文書の役割対応

| 役割・読む条件 | 実配置・状態 |
| --- | --- |
| 開始時の入口 | [AGENTS.md](../../AGENTS.md) |
| 作業分類 | [ガイド](../core/guide.md) |
| 変更・外部操作の前 | [制約](../core/policy/requirements.md) と下表の強制点 |
| 仕様・課題管理 | 未設定：既存の正本と課題の更新方法を調べる |
| ドメイン文書 | 未設定：既存のCONTEXT・ADR等の配置を調べる |
| スキルの実採用・製品差 | [採用プロファイル](skill-profile.md) |
| 検証・報告 | [検証手順](../core/procedures/verify-report.md) と下表のコマンド |
| review | 未設定：比較点・仕様の正本・適用規約とreview手段を記入する |
| 作業記録と引継ぎ | [雛形](../core/templates/worklog.md) を `harness/state/journal/<task-id>.md` へ複製。[再開手順](../core/procedures/handover.md) を使う |
| retro・ledger | [振り返り手順](../core/procedures/retrospective.md)、[台帳](../ledger.md) |

## 検証の実行場所とコマンド

既存テストを含む必須検証を実在する設定から列挙する。実行不能は代替確認と限界を別記し、必須検証を減らして解消しない。

| ID | 実行場所 | コマンド | 前提 | 期待結果 | 適用条件 |
| --- | --- | --- | --- | --- | --- |
| 未設定 | 対象ルート等を確認 | 既存の実行可能なコマンドを確認 | ランタイム・依存・権限を確認 | 終了値と出力を確認 | 必須・条件付きの範囲を確認 |

## 制約の強制点

各IDは共通制約と対応する。保護対象一覧、変更宣言、終了値、CIのPR/push差、検査の限界をここまたは既存文書に記入する。専用checkerの導入を共通の前提にしない。

| ID | 実在する強制点・種別 | 確認方法 | 既知の限界 |
| --- | --- | --- | --- |
| R1 | 未設定：実行環境・CI・報告照合を確認 | 対象版と結果の照合方法 | 誤報を拒否できる範囲を確認 |
| R2 | 未設定：保護対象・差分検査・reviewを確認 | 宣言・比較方法・終了値 | 改ざん・意味の判断の限界 |
| R3 | 未設定：製品権限・運用を確認 | 依頼と対象操作の照合 | 強制されない範囲 |
| R4 | 未設定：保存・送信前確認と既存検出を確認 | 内容・履歴の確認 | 検出の限界 |
| R5 | 未設定：上流変更の宣言・検査を確認 | profileと変更一覧の照合 | 原文一致・承認の限界 |

## OKF・既存配置・例外

- OKF採否：未設定。採用時は対象範囲、frontmatter、index、lint、stale、affectedの実コマンドと更新契機を記入。非採用は理由を記入し、OKF CLIを必須にしない。
- 上流の例示パスの読み替え：未設定。課題管理・ドメイン文書等を既存の役割へ対応させる。
- 記録保管：完了後はarchiveへ移し原則90日で見直す。恒久判断は既存の仕様・ADRへ移す。
- 任意機能の不採用：理由を明示する。必須役割・検証・制約の未設定を不採用として隠さない。
